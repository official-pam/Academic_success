# Workflow update — 24 Oct 2026

What changed, how to deploy it, and what each of the 12 requested fixes does.

## Deploy (about 10 minutes)

1. **Supabase → SQL editor → run `supabase/migrations/004_schools_courses_mentors.sql`.**
   It needs 001, 002 (+ `seed_courses.sql`) and 003 to be in place already. If you never ran
   `supabase/production-hardening.sql`, you don't need to: 004 replaces those functions.
2. **Vercel → Settings → Environment Variables → add `ADMIN_EMAILS`** = your email (comma-separate several).
   That account becomes **Admin** the next time it signs in. No SQL needed. Also confirm
   `SUPABASE_SERVICE_ROLE_KEY` is set (server only).
3. **Upload the code to GitHub** (replace files), then let Vercel redeploy. Delete
   `components/VerseBackground.js` from the repo; it's no longer used.
4. Sign in → **Committee → People and roles** → set each committee head's role and school.
5. Ask members to open **Profile** and pick their **school and programme** (a banner reminds them).

## Decisions to know about

- **Mentor access is automatic (no opt-in)**, as decided. The Privacy page and onboarding now say plainly
  who can see grades and study sessions. Check-in notes and memorised verses stay private.
  Under Nigeria's NDPA 2023, tell members this before they enter grades (the app does), and only use the data
  for academic support.
- **Grade scale**: NUC CCMAS current scale (A 70–100 = 5, B 60–69 = 4, C 50–59 = 3, D 45–49 = 2, F 0–44 = 0).
  E (40–44 = 1) can still be entered for older results. No official FUT Minna page confirms this online, so the
  committee should confirm. It lives in one place: `lib/grades.js` and `grade_for_score()` in migration 004.
- **Bible text is the WEB**, which says "Yahweh" where many Bibles say "the LORD".
- **Pinterest images can't be used** (they belong to the people who posted them). The photos are from Unsplash.
- **Phone limits**: a web app can't write directly into the phone's calendar (it hands over a calendar file instead),
  and a locked phone may delay the timer's notification. The session is still recorded correctly.
  Push notifications for mentors' phones need OneSignal (Phase 5); for now mentors see the badge and Activity in the app.
